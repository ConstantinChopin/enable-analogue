## Things that get worse, not better, when high-fidelity styling lands

1. **Vocabulary splits get frozen.** Notice/Advisory, Private/Personal, Organization/agency, Records/directory are cheap to unify now; after hi-fi they are in components, copy decks, and the presenter script.
2. **The briefing is silently the commissions index.** Commission detail is reachable only through briefing rows. Hi-fi briefings summarize (top-N); the moment the list truncates, the only path to a commission record disappears. A Commissions index (even ops-only) needs an IA home before styling.
3. **Chips do double duty.** Spec-id chips ("C-4.1") and real status chips ("overdue", "held", "1 conflict") share one primitive. Stripping annotations for hi-fi requires re-triaging every chip by hand; any status accidentally stripped is a silent trust regression.
4. **Hardcoded sheet content hides missing plumbing.** provSheet, mergeSheet, and the notice composer render fixed content regardless of what opened them. The wireframe pattern "field → static sheet" reads as done; the hi-fi build must make all three context-aware, and nothing in the wireframe marks that debt.
5. **The stale Ask crumb (verified):** once "Ask about this" scopes a thread, every later nav entry to Ask still reads "scoped to Maison Léandre", and presenter-rail reset (0) does not clear it. Harmless in grey boxes; visibly wrong once the crumb becomes styled thread-context UI.

## Ranked fix list

Demo-risk first; each fix is small.

1. **Give "Create notice" a landing.** On commit: success banner + the new notice appears in the record banner slot or the stale-review list. It is the only demo task that ends in silence. [demo-risk]
2. **Clear the resolved-conflict chip.** When `resolveBtn` fires, swap the Records directory "1 conflict" chip to a resolved state — the demo's central beat (resolve, then see it everywhere) currently contradicts itself one click later. [demo-risk]
3. **De-alias the shared stubs, or de-link the extra rows.** Maison Léandre commission row → Villa Ortensia screen; duplicate-candidate row → Hotel Sereno screen. Cheapest fix: make the second row in each list non-clickable in the wireframe; right fix: a second stub each. Also scope provSheet content per field or wire it only on the Commission field. [demo-risk]
4. **Close the advisor → Extraction review leak.** E-U5 "Request via extraction pipeline" should file a request (banner: "sent to review queue") rather than navigate an advisor onto an admin surface with no nav context. [demo-risk]
5. **Reset the Ask crumb** on nav entry and on presenter reset. [demo-risk]
6. **Block or annotate confirm-over-held.** Either disable "Confirm record" while a field is held, or have the confirmation banner say "1 field still held — excluded". Aligns the button with the copy two lines above it. [demo-risk]
7. **Unify the scope chooser** into one component with one ladder: Private → Team → Agency (pick "Private" or "Personal" once, use it everywhere; DEC-08 default preserved per context). [consistency]
8. **Pick one word: notice or advisory** — rename nav ("Stale review" → e.g. "Notices due"), sheets, and queue copy to match. [consistency]
9. **Feedback parity on commits:** every sheet commit gets the sent/stored/confirmed treatment the three good ones already have; update the read-back chip after Share VIC. [consistency]
10. **Fix button hierarchy:** solid = commit only (demote "Ask about this"; promote "Publish agency-wide"); split "Review & send" into a review step or rename to "Send". [consistency]
11. **Wire the traveller conflict** row to the shared resolveSheet (or mark it explicitly deferred) so the third conflict in the product follows the product's own conflict pattern. [consistency]
12. **Rename admin nav items** toward the vocabulary their own crumbs already use ("Extraction review" → "Confirm new records"; "Resolution queue" → "Unmatched payments"). [class-practice]

## Verdict

**Warn overall — strong IA skeleton, demo-fragile edges.** Depth, persona gating, and the shared resolve/banner primitives are genuinely good for the class; all five demo tasks land in 3–5 clicks with no backtracking. What would embarrass the live demo is not flow length but read-back: three silent commits, one stale conflict chip, three aliased stubs, and one persona leak — all one-line fixes in this codebase.
